# Cisco Packet Tracer Network Labs

Ce dépôt présente ma progression pratique en réseaux et cybersécurité à travers différents laboratoires réalisés avec Cisco Packet Tracer.

Les objectifs sont de développer mes compétences en :
- Configuration Cisco IOS
- Architecture réseau
- VLAN et routage
- Services réseau (DHCP, NAT, DNS)
- Sécurité réseau (ACL, SSH, Port Security)
- Diagnostic et résolution d'incidents

- Ce portfolio me permettra donc de m'accompagner lors de mon aprentissage des technologies réseaux et aux métiers de la cybersécurité.
